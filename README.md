# shortvideo-pipeline · 短视频内容生产工作流

把一份分镜文本变成一套可直接在剪映里精修的草稿，并补齐全部视频素材。主题不限——减脂、美食、生活、知识口播、科技演示等均可。

---

## 何时触发 / When to Use

满足任一即触发本工作流：

- 用户贴来分镜文本 / 镜头清单，并要求 **"按短视频工作流跑"**
- 用户说 **"跑短视频""分镜出片""分镜到草稿""用短视频工作流"**

> 先确认下方"风格基线"，再开始执行。若文本已随消息到达，复述基线后直接阶段 1。

---

## 风格基线 / Style Baseline

### 硬性规则（不可漂移）

| 维度 | 规则 |
|------|------|
| 形态 | 9:16 竖屏 |
| 素材 | 视频优先于图片；**拒绝 AI 静态图** |
| 来源 | **Pexels** 为主；Pexels 覆盖不到的用 **Miora 文生视频** 补 |
| 命名 | `01_`、`02_`、`03_`… 与镜头号对齐 |
| 镜头数 | 不固定，按用户文本里有多少条就跑多少条 |
| 字幕 | 关键词用**金色高亮**（正文白色），全部字幕统一 **剪映 17 号** 字号 |

### 字幕规范 / Subtitle Standard

固定样式，默认执行，不必每次确认：

| 维度 | 规则 |
|------|------|
| 字号 | 全部字幕统一 **17 号**：草稿 json 里每条字幕的 `size` 直接写 `17.0`（剪映 UI「字号」显示值 == 该 `size`，直译即可） |
| 正文颜色 | 白色 `[1.0, 1.0, 1.0]` |
| 关键词颜色 | 金色 `[1.0, 0.85, 0.2]`（≈ `#FFD933`）；同一视频内固定不换色 |
| 描边 | 黑色、宽度 `0.08`；改色时保留描边 |
| 折行 | 一行 ≤ 9 字（1080 宽 / 17 号），优先在标点后断行，标点不落行首 |

**关键词怎么挑（每句 1–2 个，最多 3 个）**

- 数字 / 量化词：`一拳`、`两拳`、`4顿`、`80%`
- 结论 / 动作词：`先吃菜`、`长期坚持`、`别搞太复杂`
- 核心概念 / 专有名词：`八二原则`、`粗粮`、`低脂`、`绿叶菜`
- 短句（≤4 字）可整句高亮；长句**禁止**整句高亮

> 高亮服务于"观众扫一眼就能抓住重点"——宁可少高亮，不要满屏发光。

### 默认画面调性

**无清晰人脸，手部 / 局部 / 物体 / 食物特写优先**——适合生活、美食、减脂、ASMR 等不依赖出镜的类型。

### 按主题动态调整

| 主题类型 | 画面调性 |
|----------|----------|
| 生活 / 美食 / 减脂 / ASMR | 无清晰人脸，手部/局部/食物特写（默认） |
| 知识口播 / 教程 | 可出镜，或半身+字幕；可保留人脸 |
| 科技 / 产品演示 | 可偏 MG 动画 / 概念镜头 / 屏幕录制 |
| Vlog / 记录 | 可出镜，叙事为主 |

## 5 阶段流程 / 5-Stage Pipeline

| 阶段 | 目标 | 工具 / Skill | 产出 |
|------|------|--------------|------|
| 1 分镜策划 | 镜头脚本定稿 | Ardot 画布 | 可编辑分镜板 |
| 2 素材规范 | 规范与命名映射确认 | 文档 | 规范文档 + 命名映射表 |
| 3 素材获取 | Pexels 为主 + Miora 补空镜 | Pexels + Miora 文生视频 | 视频素材 |
| 4 草稿搭建 | 自动生成剪映草稿 | jianying-editor (JyProject) | 剪映草稿 + `.py` 脚本 |
| 5 成片 / 发布 | 精修导出 | 剪映手动导出（60fps 在面板设）/ ffmpeg 保底渲染 | 成片 MP4 |

每阶段详细步骤见 `references/pipeline-stages.md`。

## 关键约束 / Key Constraints

1. **脚本位置**：阶段 4 生成的 `.py` 脚本放在**项目根目录 `scripts/`**，禁止写进 `jianying-editor` skill 目录。
2. **草稿分辨率**：
   - 默认 9:16 竖屏：`width=1080, height=1920`
   - 16:9 横屏：`width=1920, height=1080`
3. **环境验证**：跑阶段 4 前先运行：
   ```bash
   python <jianying-editor-skill>/scripts/api_validator.py
   ```
4. **水印去除**：AI 生成素材在归一化前必须跑：
   ```bash
   python <本skill>/scripts/watermark_auto_remove.py <视频|目录>
   ```
5. **素材形态**：Miora 仅用于文生视频 / 图生视频，**不要文生图**。
6. **个人目录安全**：桌面 `剪辑/` 是个人目录，扫描只读；移动/重命名/删除需先列清单 + 用户确认 + 备份；素材下载到归档目录属写入新文件，可正常进行。
7. **字幕样式统一**：所有批次一律「关键词金色高亮 + 全文 17 号」，实现见 `references/pipeline-stages.md` 阶段 4「字幕样式落地」；禁止逐句随机配色。
8. **60fps 只在导出面板设**：草稿 json 顶层 `fps` 必须保持 30（写成 60 会导致剪映 11.6 启动后 1–2 分钟内必崩）。

- **输入**：用户贴的分镜文本，含镜头号 + 画面描述 + 景别 + 时长 + 文案，镜头数不限，主题不限。

  1. 可编辑分镜看板
